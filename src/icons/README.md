# Icon Files

The manifest.json references icon files that should be placed in this directory:

- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels) 
- icon128.png (128x128 pixels)

You can create these icons using any image editor. For development, you can:

1. Create simple PNG files with the Moodle Downloader logo or text
2. Use online icon generators
3. Download free icons from sources like:
   - Heroicons (https://heroicons.com/)
   - Feather Icons (https://feathericons.com/)
   - Material Icons (https://fonts.google.com/icons)

Make sure the icons are relevant to downloading/education themes.

If you don't add these files, the extension will still work but won't have custom icons in the Chrome extensions interface.
