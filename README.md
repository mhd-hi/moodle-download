# Moodle Downloader Chrome Extension

A TypeScript-based Chrome Extension (Manifest V3) that allows you to selectively download course materials from Moodle platforms as organized ZIP files.

## Features

- 🎯 **Target Specific**: Works exclusively with `https://ena.etsmtl.ca/*`
- � **File Selection**: View all downloadable files with checkboxes (all selected by default)
- 📁 **Smart Organization**: ZIP files organized by course sections (tiles layout) or flat structure (standard layout)
- 🔄 **Auto URL Processing**: Automatically adds `&redirect=1` parameter for direct downloads
- 📦 **ZIP Downloads**: Single ZIP file containing all selected materials
- 🎨 **User-Friendly**: Clean popup interface with file management
- 🛡️ **Type Safe**: Built with strict TypeScript for reliability
- ⚡ **Modern Architecture**: Uses Chrome Extension Manifest V3

## How to Use

1. **Navigate** to any Moodle course page on `https://ena.etsmtl.ca/`
2. **Click** the extension icon in your browser toolbar
3. **Review** the list of downloadable files found on the page
4. **Select/Deselect** files using checkboxes (all are selected by default)
5. **Click** "Download as ZIP" to download selected files
6. **Files are organized**:
   - **Tiles layout**: ZIP contains folders named after course sections
   - **Standard layout**: ZIP contains files directly

## Installation & Setup

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Chrome browser

### 1. Install Dependencies

```bash
npm install
```

### 2. Build the Extension

For development (with source maps):
```bash
npm run build:dev
```

For production:
```bash
npm run build
```

For development with auto-rebuild:
```bash
npm run watch
```

### 3. Load Extension in Chrome

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable **Developer mode** (toggle in top right)
3. Click **Load unpacked**
4. Select the `dist/` folder from this project
5. The extension should now appear in your extensions list

### 4. Test the Extension

1. Navigate to a Moodle course page on `https://ena.etsmtl.ca/`
2. Click the extension icon in your browser toolbar
3. Review the list of files detected on the page
4. Select/deselect files as needed
5. Click "Download as ZIP" to download selected files
6. Check your Downloads folder for the ZIP file

## How It Works

### Architecture

The extension uses a three-part architecture:

1. **Content Script** (`contentScript.ts`):
   - Scans the DOM for downloadable links when requested
   - Handles both standard and tiles layout modes
   - Responds to scan requests from the popup

2. **Popup Interface** (`popup.ts` + `popup.html`):
   - Provides user interface for file selection
   - Displays discovered files with checkboxes
   - Handles user interactions and download requests
   - Communicates with content script and background

3. **Background Service Worker** (`background.ts`):
   - Creates ZIP files from selected content
   - Downloads files and packages them
   - Manages the final ZIP download

### Layout Detection

#### Standard Layout
Searches for elements matching:
```html
<div class="activityname">
  <a href="...">Activity Name</a>
</div>
```

#### Tiles Layout
Detects `<ul class="tiles" id="multi_section_tiles">` and processes each tile:
```html
<li class="tile">
  <h3>Section Name</h3>
  <!-- Activities within this section -->
</li>
```

### Download Organization

- **Standard Layout**: Files saved in flat structure within ZIP
- **Tiles Layout**: Files organized in folders named after course sections within ZIP
- **URL Processing**: Automatically appends `&redirect=1` for direct downloads
- **Filename Safety**: Sanitizes filenames to remove invalid characters
- **Error Handling**: Failed downloads become .error.txt files in the ZIP

## Configuration

### Permissions

The extension requests minimal permissions:
- `downloads`: For triggering file downloads
- `https://ena.etsmtl.ca/*`: Host permission for the target Moodle site

### Customization

To adapt for other Moodle sites:

1. Update `host_permissions` in `src/manifest.json`
2. Modify URL validation in `src/utils.ts` (`URLUtils.isValidMoodleURL`)
3. Rebuild the extension

## Debugging

### Console Logs

The extension logs activities to the browser console:
- Content script logs appear in the page's console (F12 → Console)
- Background script logs appear in the extension's service worker console:
  1. Go to `chrome://extensions/`
  2. Find "Moodle Downloader"
  3. Click "service worker" link
  4. Check the console tab

### Common Issues

1. **Downloads not starting**: Check that you're on a supported Moodle page
2. **Permission errors**: Ensure the extension has necessary permissions
3. **Build errors**: Run `npm run type-check` to identify TypeScript issues

## Troubleshooting

### Extension not loading
- Check that all files are in the `dist/` folder after building
- Verify `manifest.json` is valid JSON
- Look for errors in the Chrome extensions page

### Downloads not working
- Ensure you're on a page matching `https://ena.etsmtl.ca/*`
- Check browser console for error messages
- Verify download permissions are granted

### Build issues
- Delete `node_modules/` and run `npm install` again
- Ensure Node.js version is 16 or higher
- Check that all TypeScript errors are resolved
