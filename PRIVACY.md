# Moodle Downloader Privacy Policy

Last updated: October 10, 2026

Moodle Downloader is a browser extension for downloading course materials from Moodle pages.

## Data handling

The extension reads the currently displayed Moodle course page only after the user starts a scan. It reads course links, titles, tab text, and images so it can organize selected materials into a ZIP archive. This content is processed locally in the browser and is not sent to the extension author or any analytics service.

The extension stores the following locally in Chrome extension storage:

- Download history, so previously downloaded files can be skipped.
- User preferences, such as the skip-already-downloaded setting.
- Temporary scan and download state, so the popup can recover if it is closed.

The extension does not collect, sell, or transfer personal information, passwords, authentication credentials, payment information, browsing history, or course materials to third parties. Downloads are requested from the Moodle installation the user is already signed into and are packaged locally in the browser.
